# ⚡ Power Outage Management System

A Java-based web application developed using JSP, Servlets, JDBC, MySQL, HTML, and CSS following the MVC architecture. The system provides a centralized platform for reporting and managing power outage complaints with dedicated portals for Citizens, Technicians, and Administrators.

## 🚀 Features

- Secure role-based authentication
- Citizen complaint registration
- Power outage reporting
- Complaint status tracking
- Technician assignment and management
- Admin dashboard
- Feedback management
- MVC architecture using JSP and Servlets

## 🛠️ Tech Stack

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat
- Eclipse IDE
